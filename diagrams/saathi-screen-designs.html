O1 — Welcome & Language

First launch only. The single most important tap in the app.

Behaviour

  • Language choice sets language_pref for every label, notification, and AI explanation from here on — switchable any time from the top bar toggle
  • Nepali is listed first and preselected — the wedge audience is Nepali-first, English is the fallback, never the reverse

Options

  • नेपाली (default) — UI chrome bilingual, explanations Nepali-primary
  • English — same features, EN-primary with NP labels preserved on legal/disclaimer text

Guards

  • No marketing copy, no permissions requests, no signup wall on this screen — one decision only

O2 — Feature Discovery Cards

Four swipeable cards, one per feature. Progressive disclosure — never a feature-grid dump.

Behaviour

  • Each card's CTA deep-links straight into that feature's first useful screen (Tracker → Add Visa, Calculator → Start, etc.)
  • Skip is always visible — onboarding is an offer, not a gate

Card copy (worked examples)

  • Tracker: "म्याद सकिनु ६ महिना अगाडि नै रिमाइन्डर" — leads with the fear it solves (missed deadline)
  • Calculator: "एजेन्टकहाँ जानु अघि आफ्नो अंक थाहा पाउनुहोस्" (know your score before paying an agent $300)

O3 — Quick Setup (optional)

One question that personalises everything else. Fully skippable.

Behaviour

  • Answer pre-filters F1's subclass picker, F3's visa cards, and orders F4's form list (500-holders see 485 content surfaced next — the journey view)
  • "Not sure" is a first-class option → lands on the home screen with all features neutral, plus a hint card linking to F1's subclass explainer

Guards

  • Stored locally until an account exists — no signup required to answer
  • This is NOT an eligibility question — copy never implies "we'll tell you what visa to get"

F1.3 — Add Visa, Step 2: Dates

Two date fields with a "where do I find this" helper — the single most-asked support question, answered inline.

Options

  • Enter both dates (normal path)
  • "I only know the expiry date" — grant date optional, countdown still works
  • Date picker defaults to the DD MMM YYYY format grant letters use

Guards

  • Expiry before today → warning state, offers Bridging-visa guidance link instead of a silent countdown of negative days
  • Expiry > 5 years away → "double-check this date" nudge (typo catcher)

F1.5 — Dashboard (Active Visa)

The retention screen — the one users reopen. Countdown ring is the hero.

Behaviour

  • Ring colour: green >90 days · amber 30–90 · red <30 (state F1.6)
  • "Next step" card cross-sells the journey (500→485 checklist) — informational framing only, never "you should apply for X"
  • Multi-visa: horizontal card switcher above the ring; each visa keeps its own reminders

Options

  • Tap conditions → full-screen detail with citations
  • Tap reminders → per-threshold toggle sheet (F1.6 annotation)
  • Edit / delete visa via overflow menu

Offline

  • Fully readable offline from cache; edits queue and sync — banner: "अफलाइन · showing saved data"

F1.6 — Expiry Warning (<30 days) + Push

Theme shifts red; dashboard becomes an action list. Push notification shown in-frame.

Push content (worked examples)

  • 180d: "६ महिना बाँकी — आराम छ, तर योजना सुरु गर्नुहोस्" (calm tone)
  • 30d: "२८ दिन बाँकी छ। अर्को कदम हेर्नुहोस्" (urgent, taps open this screen)
  • 7d: "७ दिन! विकल्पहरू हेर्नुहोस् वा MARN एजेन्टसँग कुरा गर्नुहोस्" (last call + handoff)

Behaviour

  • Action items are informational framings ("decide between…", "must be lodged before…"), each cited — never "apply for 485"
  • MARN handoff line is mandatory on every urgent state

Options

  • Per-threshold notification toggles (180/90/30/7 each on/off) in a settings sheet
  • iOS Safari without push permission → in-app banner fallback on next open (§16 risk #5)

F2.2 — Question Step (pattern for all 12)

One question per screen; points shown inline on every option — the calculator teaches the rules as it asks.

The 12 criteria (order)

  • Age → English → work exp (overseas) → work exp (AU) → qualification → AU study req → specialist edu → community language (NAATI) → regional study → partner skills → Professional Year → nomination/family

Behaviour

  • Back never loses answers; state persists locally across app restarts
  • 45+ answer shows an inline honest note (0 points, GSM age limit) with a cited source — it does not block completing the wizard

Guards

  • Every points value comes from gsm-points.json with a last-updated date — no hardcoded numbers in UI code

F2.3 — English Score Input (the complex field)

Test-type tabs + per-band entry; the mapper computes the points tier live and explains why.

Behaviour

  • Score mapper: IELTS/PTE/TOEFL/OET band thresholds → Competent (0) / Proficient (10) / Superior (20), computed as the user types
  • The "why" line is the teaching moment — here: one 6.5 band blocks Proficient. This exact confusion costs people agent consult fees

Options

  • "I haven't taken a test yet" → assumes Competent (0 pts), flags it in results as the top improvement lever
  • Test date field → warns if result will be >3 years old (validity window), cited

F2.5 — Compare Mode (saved + what-if)

Saved runs side-by-side; what-if scenarios are visually distinct (dashed) from real answers.

Options

  • Duplicate any saved run → edit one answer → see the delta
  • Delete saved runs; all user-scoped, requires account

Guards

  • What-if cards are labelled "hypothetical" in both languages — never mistakable for an achieved score
  • If the points rules JSON has updated since a save, the old card shows "rules changed since this was calculated — recalculate"

F6.6 — My Enquiries & Data Controls

Every enquiry's status plus per-agent revocation of shared data — consent is a living control, not a one-time checkbox.

Behaviour

  • Statuses: Sent → Viewed → Responded → Closed (or Withdrawn); a proposed call time can be accepted → .ics + FCM reminder, reusing F5's event plumbing
  • Revoke → agent notified with deletion obligation; enquiry closes; the audit log records the full share/revoke history

Options

  • Withdraw an unanswered enquiry any time
  • Post-consult one-tap feedback ("did the agent respond professionally?" yes/no) — feeds delisting decisions, not public ratings
