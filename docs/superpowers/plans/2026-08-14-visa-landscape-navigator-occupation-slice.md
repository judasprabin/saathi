# Visa Landscape Navigator — Occupation Slice Implementation Plan

> **SUPERSEDED (2026-08-14):** this feature's backend and frontend now live in separate repos — [`koshi`](https://github.com/judasprabin/koshi) and [`lukla`](https://github.com/judasprabin/lukla) — each with their own design spec and (forthcoming) implementation plan. Tasks 1–5 below (schema, seeds, endpoint, insights) are the direct reference for koshi's first plan; Tasks 6–8 (Next.js scaffold, occupation section, design tokens) are the direct reference for lukla's. Kept here, unexecuted, as historical reference and as the concrete starting point for both new plans — do not execute this plan in the saathi repo.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first real, end-to-end vertical slice of the Visa Landscape Navigator — a working "Your Occupation" section (ceiling-usage gauge, list-status badges, deterministic insight text) backed by a real Postgres-shaped schema and a real FastAPI endpoint, with a Next.js frontend that live-switches between two occupations by fetching from that endpoint.

**Architecture:** FastAPI + SQLAlchemy + Alembic backend (Cloud SQL Postgres in production, SQLite for unit tests) exposing `GET /api/occupations/{code}`; a Next.js 14 App Router frontend that fetches from it. No LLM anywhere in this slice — ceiling data is seeded (bato-style YAML seeds) and "what this means" insight text is generated by a deterministic template function, matching design spec §6.1/§9.5.

**Tech Stack:** Python 3.11+, FastAPI, SQLAlchemy 2.0, Alembic, pytest; TypeScript, Next.js 14, Vitest, Testing Library.

**Scope note:** This plan covers only the Occupation slice (2 seeded occupations: Software Engineer 261313, Registered Nurse 254111 — matching the approved mockup). State, Options/visa-comparison, National, and Reference sections are deliberately out of scope here — they are separate follow-on plans once this pattern (schema, provenance, insight templates, API shape, frontend fetch pattern) is validated. Do not add those sections to this plan.

## Global Constraints

These apply to every task below; do not relax them locally.

- **No personalized-prediction or advice language anywhere in generated copy** — describe published facts only, never "you should/can/are eligible/will" (design spec §6.4). Any user-facing string generation must have a test asserting this.
- **All natural-language copy (insight text) is deterministic/templated, never LLM-generated** (design spec §6.1, §9.5).
- **Every fact-bearing DB row carries `source_url` and `retrieved_at`** — provenance is not optional (design spec §9.2).
- **Status colors (`--good`/`--warning`/`--critical`) must never equal any categorical slot (`--s1`–`--s4`)** — this is a specific, previously-found bug (design spec §9.4); Task 8 fixes and regression-tests it.
- **Backend tests never require a live Postgres** — use in-memory SQLite for unit tests (matches manaslu/bato's "tests run without real external dependencies" discipline). Alembic migrations are exercised manually/in CI against real Postgres, not in this test suite.
- **Frontend tests never make real network calls** — mock `fetch`.

```python
from alembic import context
from sqlalchemy import engine_from_config, pool

)

if config.config_file_name is not None:
    fileConfig(config.config_file_name)

target_metadata = Base.metadata


def run_migrations_offline() -> None:
    url = config.get_main_option("sqlalchemy.url")
    context.configure(url=url, target_metadata=target_metadata, literal_binds=True)
    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online() -> None:
    connectable = engine_from_config(
        config.get_section(config.config_ini_section, {}), prefix="sqlalchemy.", poolclass=pool.NullPool
    )
    with connectable.connect() as connection:
        context.configure(connection=connection, target_metadata=target_metadata)
        with context.begin_transaction():
            context.run_migrations()


if context.is_offline_mode():
    run_migrations_offline()
else:
    run_migrations_online()
```

- [ ] **Step 4: Write `scripts/load_seeds.py`**

```python
import datetime
from pathlib import Path

import yaml
from sqlalchemy.orm import Session

from api.models import CeilingUsage, Occupation

SEEDS_PATH = Path(__file__).resolve().parent.parent / "seeds" / "occupations.yaml"


def load_seeds(session: Session, path: Path = SEEDS_PATH) -> int:
    data = yaml.safe_load(path.read_text())
    count = 0
    for row in data["occupations"]:
        occ = session.get(Occupation, row["code"])
        if occ is None:
            occ = Occupation(code=row["code"], name=row["name"], lists=row["lists"])
            session.add(occ)
        cu = row["ceiling_usage"]
        usage = CeilingUsage(
            occupation_code=row["code"],
            program_year=cu["program_year"],
            issued=cu["issued"],
            ceiling=cu["ceiling"],
            as_of_date=datetime.date.fromisoformat(cu["as_of_date"]),
            source_url=cu["source_url"],
            retrieved_at=datetime.datetime.fromisoformat(cu["retrieved_at"]),
        )
        session.add(usage)
        count += 1
    session.commit()
    return count


if __name__ == "__main__":
    from api.db import SessionLocal

    db_session = SessionLocal()
    try:
        n = load_seeds(db_session)
        print(f"Loaded {n} occupations")
    finally:
        db_session.close()
```

```python
from fastapi import Depends, FastAPI, HTTPException
from sqlalchemy.orm import Session

from api.db import get_db
from api.models import Occupation
from api.schemas import CeilingUsageOut, OccupationOut

app = FastAPI(title="Saathi API")


@app.get("/api/health")
def health() -> dict[str, str]:
    return {"status": "ok"}


@app.get("/api/occupations/{code}", response_model=OccupationOut)
def get_occupation(code: str, db: Session = Depends(get_db)) -> OccupationOut:
    occ = db.get(Occupation, code)
    if occ is None:
        raise HTTPException(status_code=404, detail=f"No occupation with code {code}")
    latest = max(occ.ceiling_usages, key=lambda u: u.as_of_date)
    pct = round(latest.issued / latest.ceiling * 100)
    return OccupationOut(
        code=occ.code,
        name=occ.name,
        lists=occ.lists.split(","),
        ceiling_usage=CeilingUsageOut(
            issued=latest.issued,
            ceiling=latest.ceiling,
            pct=pct,
            program_year=latest.program_year,
            source_url=latest.source_url,
        ),
        insight="",
    )
```

```python
def occupation_ceiling_insight(name: str, issued: int, ceiling: int) -> str:
    """Deterministic 'what this means' text for an occupation's ceiling usage.

    Template-based, not LLM-generated — mirrors bato's ingest/cards.py pattern
    for turning structured facts into natural-language sentences without an
    LLM call. Describes published, factual numbers only — never a personalized
    outcome or eligibility judgment (design spec §6.4).
    """
    left = ceiling - issued
    pct = issued / ceiling
    if pct >= 0.8:
        return f"Only {left:,} places left this year for {name} nationally."
    if pct >= 0.5:
        return f"{left:,} places left this year for {name} — filling steadily."
    return f"{left:,} places left this year for {name} — plenty of room so far."
```
